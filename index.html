AICappr — published cards

Every card's SHA-256 fingerprint is posted on X (@AICappr) before its games tip off, as a reply under that day's picks post. The card itself — the actual picks and results below — is published here only after the games, so you can check that the fingerprint posted beforehand matches.

How to check one yourself. You need two files from the same card: the card file and its Bitcoin proof (the .ots file) — download both using the links under the card below.
  1. Easiest — just confirm the fingerprint: go to opentimestamps.org, and either drag both downloaded files onto the page together, or use its Verify option and attach both when it asks. It will show you the file's hash and the Bitcoin block it was timestamped in. That hash must match the SHA-256 shown under the card below, and that SHA-256 must match what was posted on X before the games started — proving the pick was locked in before anyone knew the result.
  2. Extra — check the hash yourself first: on a Mac or Linux terminal, shasum -a 256 2026-11-09-card1.txt (Windows: certutil -hashfile 2026-11-09-card1.txt SHA256) and compare the result to the SHA-256 shown below.
Each card also includes a random salt, so the fingerprint can't be guessed from the picks alone.
