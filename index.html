AICappr — published cards

Every card's SHA-256 fingerprint is posted on X (@AICappr) before its games tip off. The card file is published here only after the games, with the results.

Check a card yourself. Download its file, then on a Mac or Linux terminal run shasum -a 256 2026-11-09-card1.txt (Windows: certutil -hashfile 2026-11-09-card1.txt SHA256). The result must match the fingerprint posted on X before the games. Each card also includes a random salt, so the fingerprint can't be guessed from the picks. Where there's a proof file, it's an OpenTimestamps anchor in the Bitcoin blockchain: check it at opentimestamps.org.
